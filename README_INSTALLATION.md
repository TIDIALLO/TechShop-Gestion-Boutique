\# TechShop Electronics — Guide d'installation



\## 1. Versions utilisées et recommandées



Le projet a été testé avec les versions suivantes :



\### Backend

\- Python : 3.13.x

\- Django : 5.1.7

\- Django REST Framework : 3.15.2



\### Frontend

\- Node.js : 22.x

\- npm : 10.x



> Il est recommandé d'utiliser ces versions majeures pour éviter les problèmes de compatibilité.
